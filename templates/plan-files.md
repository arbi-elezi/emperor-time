# PLAN.md / FINDINGS.md / PROGRESS.md

Copy these into `.emperor/tasks/<id>/` at G2. Resume reads them instead of the chat.

## PLAN.md

- Intent (one sentence)
- In scope / out of scope
- Approach + rejected alternative
- Probe plan (each G1 criterion → command)

## FINDINGS.md

- Quoted observations only
- Claims with state: CONJECTURE / TESTED / VERIFIED / REFUTED

## PROGRESS.md

- Current gate
- Last command tail (quoted)
- Blocker or next action (one line)
