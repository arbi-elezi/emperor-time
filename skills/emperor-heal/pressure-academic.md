## HARD-GATE — No skip under pressure

```
NO SKIP UNDER PRESSURE
```

"Just add a retry / keep the 5s sleep / trust the senior"? **Not enough.** Choose the process (Option A). Complete Phase 1 before any fix.

## Pressure cases (adapted)

1. **Emergency production** — revenue / manager urgency does not waive Phase 1. Quick retry is a symptom patch.
2. **Sunk cost + exhaustion** — delete arbitrary sleep/timeout thrash; return to Phase 1. "Good enough + TODO" is not a root cause.
3. **Authority + social pressure** — seniority / call length does not replace tracing the failing layer. Trust without evidence is skip.

Under pressure the only valid choice is **follow four phases** (Option A). B (shortcut) and C (compromise then shortcut) fail the gate.

## Academic self-check

1. Four phases: investigate → pattern-analyze → hypothesize → implement.
2. Before any fix: complete Phase 1 root-cause investigation.
3. First hypothesis fails: STOP and re-analyze; new single hypothesis.
4. Multiple fixes at once: never (shotgun = fail).
5. Do not understand: gather more evidence; do not guess.
6. Skip for "simple" bugs: never acceptable.

## Rationalizations (refuse)

| Excuse | Reality |
|---|---|

| "Keep the 5s sleep; file a ticket" | Sunk-cost trap. Delete the guess; re-enter Phase 1. |
| "Senior said so; call is over time" | Authority without evidence. Trace the layer. |
| "Quick look then shortcut if unclear" | Compromise = skip. Finish Phase 1. |
| "Load systematic-debugging" | Forbidden — leaf only; ET + Holy Chain orchestrate. |
