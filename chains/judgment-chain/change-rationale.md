# Change rationale — fact-check the hunk before it lands

Every production edit answers, in the ledger, before the write:

```
CHANGE: <path>
SERVES G1: <line>
OBSERVED NOW: <quote 1–3 lines from the file as it is>
WHY THIS HUNK: <one sentence>
PROBE AFTER: <command already in DONE.md or work-order>
```

No OBSERVED NOW quote → you are editing a rumor. Re-read the file.
No SERVES G1 → scope-guard.
"Cleanup while I am here" is creep unless G1 named it.
