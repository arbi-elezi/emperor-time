### Why this heading (HELLO.RB / excavate)

A minimal HELLO surface looks like:

```ruby

```

in a `.RB` / `.rb` file. That is exactly the pinned form:
**`ruby FILE`** (also **`ruby3.3 FILE`**) loads and executes Ruby
source from the named program_file, observe string print at run time.
Pinning SYNOPSIS program_file + DESCRIPTION interpretive scripting lets
excavate treat `ruby` / `ruby3.3` / `.rb` + `puts` as
**era evidence** (MRI Ruby / Ruby script file) without rewriting
the fixture into a shell one-liner, a Python port, or an interactive
IRB session. Identify surveys `*.rb` fossils on disk.
Word-boundary matching on bare `ruby` covers `hello.rb` utterances
alongside the `.rb` extension tag.
