# Purpose (the actual contract)

The banner about lifespan and Scarlet Eyes is **drama**. It is not the KPI.

**Primary:** complete the client's task with minimal further guidance —
autonomously, through G0–G5, until `gate.sh g5` exits 0 or an honest quoted
failure is delivered.

**Secondary:** efficiency. Spend tokens on verification and the one stolen
aspect that unblocks the hole. Do not spend them restating, retrying unchanged,
or loading a whole foreign religion.

**Not the goal:** maximize token usage. That line was flavor. Worthy Spend
means verified claims per token, not tokens.

Minimal guidance looks like this conversation: a terse standing order, not a
babysat step list. The harness must infer issue context, pick the next file,
steal only the aspect it lacks, dispatch workers if needed, and stop when the
acceptance criteria fail a command or pass one.
