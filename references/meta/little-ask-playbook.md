# Little-ask playbook

What **tiny** skips vs **never** skips. Iron consent stays.

## Tiny may skip / soft-scale

- Eight-count critique museum (harness forbids critique on tiny)
- Excavate / sandbox / SOT up (forbidden on tiny FORCE_TABLE)
- Hetero review-pack isolation when unused
- Worktree for one-line edits
- Long archaeology manuals / Nen lore / k8s emitters

## Tiny never skips (iron)

- Ask→spec before setup thrash (`--require-spec`)
- Harness plan emit (`--require-plan`) — tiny plan is short, not absent
- Quote the tail / prediction-before-command when a claim is made
- Forge PR-consent before public PR
- Pin-and-consent before captured skill fire
- Quarantine / steal-consent / secrets-no-leak
- `emperor done` exit 0 before saying done
- User override of effort_class (config / explicit / "use full rigor")

## Operator flow

1. `emperor rigor-judge --ask "<ask>"` (or ask-spec emit auto-stamps)
2. If tiny: do-once, proportional verify, no museum
3. If secrets/forge/archaeology signals fire: judge bumps class — honor it
4. Explicit class always wins
