# When to engage Emperor Time

Load on demand (SessionStart lists this path only — do not inline).

## Engage (full factory)

- High-stakes verify, regulated evidence, brownfield / lost trees
- Multi-agent critique under consent; forge / public PR
- Secrets, auth, pin-and-consent, quarantine / steal
- Explicit "emperor time" / "use full rigor" / effort_class medium|large|full

## Prefer tiny / little-ask

- Typo, wording, one-line, changelog-only, single-file nit
- Config knob tweak with no blast radius
- See `references/meta/little-ask-playbook.md`

## Do not engage as

- Default daily autocomplete skill (positioning: full-rigor factory, not Superpowers replacement)
- Archaeology museum growth / Nen lore / k8s emitter churn without field failure

## Router

`scripts/emperor rigor-judge --ask "<ask>"` → recommended `effort_class`.
User override always wins (`--effort-class`, config, "use full rigor").
