### Why this heading (HELLO.SNO / excavate)

A minimal HELLO surface looks like:

```snobol4
        OUTPUT = "EMPEROR-TIME-SNO-PROBE-OK"
END
```

in a `.SNO` / `.sno` file. That is exactly the pinned form:
`snobol4` **reads the named source file(s)** after options, observe
`OUTPUT` assignment at run time. Pinning SYNOPSIS lets excavate treat
snobol4 + `.sno` + `OUTPUT` as **era evidence** (SNOBOL4 interpreter /
source file) without rewriting the fixture into pattern matching,
`REPLACE`, or a Python port.

**Dialect precision:** this pin authorizes CSNOBOL4 reading of the
`OUTPUT =` / `END` / command-line *file* shape only. It does **not**
claim the lost tree is period Bell Labs Macro SNOBOL4 on original
media, a specific printing of Griswold *The SNOBOL4 Programming
Language*, or SPITBOL/SITBOL. Those are other manuals. HELLO's
"Macro-SNOBOL4-ish / OUTPUT subset" label remains **CONJECTURE** until
a dialect-specific vendor run is evidence — `snobol4` accepting the
`OUTPUT` shape and printing the probe string is the VERIFIED claim for
this leaf.
